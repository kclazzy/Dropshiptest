# Dropshiptest

Локальная гибридная система автоматизации дропшиппинга: **C++20 ядро** + **расширение браузера (Manifest V3)** + **локальная LLM (Ollama)**. Работает на ПК пользователя, без облачных посредников. Модель данных рассчитана на несколько площадок, включая Ozon, Avito, Wildberries, Яндекс Маркет, Shopify, WooCommerce и eBay.

## Структура

```
core-cpp/          C++20 ядро (CMake, vcpkg)
  src/core/        Domain.hpp (Platform, TaskType, Cents), Expected.hpp
  src/pricing/     PricingEngine: цена в int64 копейках, диапазонные правила, мин. прибыль
  src/db/          DatabaseManager: SQLite WAL, миграции, история, очередь задач
  tests/           юнит-тесты без внешних зависимостей
extension-mv3/     расширение браузера (TypeScript, Vite) — исходники в Шаге 2
docs/              журнал разработки и глоссарий
```

## Сборка и тесты (ядро)

```bash
cd core-cpp
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
```

Нужны компилятор C++20 (GCC 13+, Clang 16+, MSVC 19.34+), CMake 3.25+ и SQLite3 (системный или через vcpkg: `-DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake`).

## Что уже есть (Шаг 1)

- **Деньги без float:** суммы в минимальных единицах, проценты в базисных пунктах; переполнение — ошибка, а не UB.
- **PricingEngine:** `P = (C + S + F) × (1 + маржа) / (1 − комиссия)`, диапазоны по закупочной цене, психологическое округление (`.99`, `.90`, …), флаг минимальной прибыли, защита остатков.
- **База данных:** WAL, один писатель + пул читателей, параметризованные запросы, идемпотентные миграции.
- **Редактирование и история для пользователя:** правки названия/описания/заметок хранятся отдельно от данных поставщика; `price_history` (цены и остатки) и `audit_log` (правки карточек, статусы заказов) заполняются триггерами; представление `v_product_overview` отдаёт список товаров для GUI.
- **Очередь задач:** атомарный захват (`UPDATE … RETURNING`), приоритеты, повторы с задержкой, возврат «брошенных» задач.
- **Валюта магазина** (`stores.currency`) — для площадок в рублях.

## План

| Шаг | Содержание |
|---|---|
| 1 ✅ | База данных, PricingEngine, каркас репозитория |
| 2 | `OllamaClient` (Structured Outputs), WebSocket-сервер для расширения, исходники расширения |
| 3 | Мониторинг цен/остатков (`curl_multi`, прокси, хэш состояния) |
| 4 | Адаптеры магазинов `IStoreAdapter` (Shopify, WooCommerce, eBay, Ozon, Avito, …) |
| 5 | Автовыкуп и трекинг через расширение |
| 6 | GUI (Dear ImGui): список товаров, правка карточек, графики истории цен |

> Адаптеры Ozon и Avito появятся в Шаге 4. Перед реализацией нужно проверить, какие операции (публикация, остатки, заказы) их официальные API реально разрешают для вашего типа аккаунта: возможности и ограничения у площадок разные.
