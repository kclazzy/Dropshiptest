# Расширение браузера (Manifest V3)

Мост между браузером и локальным приложением Dropship.

## Что умеет
- **Добавить товар с этой страницы** — собирает название, фото, варианты и цены (JSON-LD/микроразметка) и отправляет в приложение.
- **Передать сессию сайта** — cookies поставщика уходят в приложение (шифруются AES-256-GCM) для мониторинга закрытых страниц.
- **Заказы** — список заказов и помощь при выкупе (приложение открывает страницу товара, оплату подтверждаете вы).

## Привязка (один раз)
1. В приложении: **Настройки → Расширение → Привязать** — появится код из 8 символов (действует 2 минуты).
2. В окне расширения: **Настройки → Код привязки → Привязать**.

Токен выдаётся ядром и хранится только в `chrome.storage.local`; в базе приложения — лишь его SHA-256.

## Сборка и проверка
```bash
npm ci && npm test && npm run build   # dist/ — распакованное расширение
```
Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `dist`.

Соединение: `ws://127.0.0.1:8765/ws` (только localhost, только Origin `chrome-extension://`).
