# ИИ для карточек: Ollama и облачные сервисы

Приложение умеет писать заголовок, описание, характеристики и теги для Ozon, Avito и обычных магазинов.
Для этого нужна **одна** из моделей: бесплатная на вашем компьютере (Ollama) или платная облачная.
Переключаться можно в любой момент: **Настройки → ИИ**.

> ⚠ Адреса, названия моделей и ссылки ниже указаны по памяти и не сверены с актуальной документацией провайдеров — они меняются.
> Если что-то не подошло, откройте страницу провайдера и поправьте значения в настройках (поля «Адрес» и «Модель» можно менять).

## Что выбрать

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Ollama** (локально) | бесплатно, тексты товаров не покидают компьютер | нужна видеокарта или терпение: на слабом ПК медленно; скачивание модели ~5–6 ГБ |
| **Облако** | быстро, не нужен мощный ПК, качество выше | платно (центы за карточку), текст товара уходит провайдеру |

Совет: для старта — облачная модель из дешёвых (`gpt-4o-mini`, `gemini-2.0-flash`, `claude-haiku-5-5`, Groq/Mistral). Когда освоитесь — решайте, нужна ли Ollama.

## Ollama (локально)
1. Скачайте и установите Ollama: https://ollama.com/download
2. Скачайте модель (по умолчанию `qwen3.5:9b-q4_K_M`): в терминале `ollama pull qwen3.5:9b-q4_K_M`. Если такой модели нет, возьмите любую из каталога https://ollama.com/library и впишите её имя в поле «Модель».
3. Оставьте Ollama запущенной (значок в трее). Адрес по умолчанию `http://127.0.0.1:11434` — менять не нужно.
4. В приложении: Настройки → ИИ → «Ollama» → «Проверить».

## Облачные сервисы
Для каждого: **создайте аккаунт → пополните баланс (если требуется) → создайте ключ → вставьте ключ в Настройки → ИИ**. Ключ показывается один раз — скопируйте его сразу.

| Сервис | Где взять ключ | Модель по умолчанию |
|---|---|---|
| OpenAI | https://platform.openai.com/api-keys | `gpt-4o-mini` |
| Anthropic (Claude) | https://console.anthropic.com/settings/keys | `claude-haiku-5-5` |
| Google Gemini | https://aistudio.google.com/app/apikey (есть бесплатный лимит) | `gemini-2.0-flash` |
| OpenRouter | https://openrouter.ai/keys (один ключ — много моделей) | `openai/gpt-4o-mini` |
| Groq | https://console.groq.com/keys (бесплатный лимит) | `llama-3.3-70b-versatile` |
| Together AI | https://api.together.ai/settings/api-keys | `meta-llama/Llama-3.3-70B-Instruct-Turbo` |
| Mistral | https://console.mistral.ai/api-keys | `mistral-small-latest` |
| DeepSeek | https://platform.deepseek.com/api_keys | `deepseek-chat` |

### Любой другой сервис («Другой сервис»)
Подходит всё, что понимает формат OpenAI (`/chat/completions`): LM Studio, vLLM, облака с «OpenAI-совместимым» режимом. Укажите:
- **Адрес** — например `http://127.0.0.1:1234/v1` (LM Studio) или `https://…/v1` у облака;
- **Модель** — точное имя из кабинета сервиса;
- **Ключ** — если сервис его требует.

## Безопасность и приватность
- Ключ хранится в базе **только зашифрованным** (AES-256-GCM); ключ шифрования — файл `secret.key` в папке данных. Сделайте его резервную копию: без него сохранённые ключи не расшифровать.
- Ключ отправляется только на указанный адрес и **только по https** (по http — лишь на этот компьютер). Переадресации не выполняются.
- В облако уходит название, описание и характеристики товара поставщика — не данные покупателей, не ключи магазинов.
- Тексты с «реплика», «копия», «подделка» и т. п. приложение не отправляет в модель и не публикует (список можно расширить).

## Если не работает
| Сообщение | Что делать |
|---|---|
| «Нет связи с ИИ» | Ollama: запущена ли? Облако: есть ли интернет, верен ли адрес |
| «Провайдер не принял ключ» | Скопируйте ключ заново целиком, проверьте баланс и срок действия |
| «Провайдер ограничил число запросов» | Подождите — приложение повторит само; либо смените тариф/модель |
| «ИИ вернул ответ, который не удалось разобрать» | Приложение повторит; если повторяется — выберите модель покрупнее |
| Карточка в статусе `ERROR` | Причина записана в журнале задачи; частые: запрещённые слова в исходном тексте, неверный ключ |
