# Dropship — инструкция пользователя

Что делает программа: вы открываете страницу товара у поставщика (в любом интернет-магазине), нажимаете кнопку в расширении — товар попадает в локальную базу, а ИИ готовит для него название, описание и теги. История цен и ваши правки хранятся отдельно от данных поставщика и ничего не теряют.

**Состав:** ядро (программа `dropship_core_app`) + расширение для Chrome/Edge/Brave + ИИ (локальная Ollama или любое облако).

> **Что уже работает, а что ещё нет.** Работает: импорт товара с любой страницы, база с историей и журналом правок, генерация карточки ИИ (локально и в облаке), обновление в один клик, запуск в облаке. **Ещё не готово:** автоматический мониторинг цен, публикация на Ozon/Avito и др. (адаптеры площадок), автовыкуп и окно с таблицей товаров. Пока смотреть и править данные можно через `sqlite3` (раздел 6). Подробности — в таблице «План» в README.

## 1. Установка (Linux/macOS)

Нужны: `git`, `cmake` 3.25+, компилятор C++20 (GCC 13+/Clang 16+), библиотеки SQLite3, OpenSSL, libcurl, Boost (заголовки), nlohmann-json, и Node.js 20+ для расширения. Для Ubuntu:

```bash
sudo apt install git g++ cmake ninja-build libsqlite3-dev libssl-dev libcurl4-openssl-dev libboost-dev nlohmann-json3-dev nodejs npm
git clone https://github.com/kclazzy/Dropshiptest.git
cd Dropshiptest
scripts/build.sh
```

Windows: ядро собирается через vcpkg (`core-cpp/vcpkg.json`) и CMake, запуск — `scripts\run.cmd`. Сборка под Windows пока **не проверялась** — если что-то не получится, напишите, что показала ошибка.

## 2. Запуск ядра

```bash
scripts/run.sh
```

В окне появится строка «Dropship core … is running». Данные хранятся в `~/.dropship` (или в папке из `--data-dir`/`DROPSHIP_DATA_DIR`):

| Файл | Что это |
|---|---|
| `dropship.db` | вся база: товары, варианты, история цен, журнал правок |
| `bridge.token` | пароль для расширения (64 символа). Никому не показывайте |
| `settings.json` | настройки ИИ и обновлений |

Остановить — `Ctrl+C`. Запускайте именно через `scripts/run.sh`: только так работает кнопка обновления.

## 3. Установка расширения

1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension-mv3/dist`.
3. Нажмите значок Dropship → «Настройки» → вставьте содержимое файла `bridge.token` → «Сохранить».
4. Вверху должно появиться «Связь с ядром установлена».

Расширение просит минимум прав: оно ничего не запускает на сайтах само — только когда вы нажимаете кнопку.

## 4. Добавление товара (Ozon, Avito и любые другие сайты)

1. Откройте страницу **конкретного товара** у поставщика.
2. Нажмите значок Dropship → «Добавить товар с этой страницы».
3. Появится «Добавлено: …». Повторное добавление того же товара не создаёт дубликат (ссылки с `utm_` и т. п. считаются одной ссылкой).

Расширение читает стандартную разметку магазинов (schema.org/JSON-LD, Open Graph). Если сайт её не отдаёт, вы увидите «Не удалось найти цену» — тогда товар пока добавить нельзя.

Товары попадают в «Мой каталог» — локальный магазин, который создаётся при первом запуске. Когда появятся адаптеры Ozon/Avito, товары можно будет привязывать к вашим магазинам на этих площадках; поле «Номер магазина» в настройках расширения нужно только тогда.

**Сессия поставщика.** Кнопка «Передать сессию сайта в ядро» отправляет куки текущего сайта в память ядра (на диск они не пишутся) — нужно для будущего мониторинга закрытых страниц. Браузер спросит разрешение отдельно для этого сайта.

## 5. ИИ: описание, заголовок, теги

По умолчанию — локальная Ollama (бесплатно, данные не уходят с компьютера):

```bash
ollama pull qwen3.5:9b-q4_K_M      # модель по умолчанию; если такой нет — выберите другую и впишите в settings.json
```

Облачные провайдеры (OpenAI, Claude, OpenRouter, Groq и др.) подключаются в `settings.json`; пошаговая инструкция — в [CLOUD.md](CLOUD.md). После правки `settings.json` перезапустите ядро.

Результат ИИ не затирает ваши правки: приоритет «ваш текст → текст ИИ → оригинал поставщика».

## 6. Просмотр товаров, истории и правок

Пока без окна: нужна утилита `sqlite3` (`sudo apt install sqlite3`).

```bash
sqlite3 -header -column ~/.dropship/dropship.db \
  "SELECT id, title, ai_status, variant_count, total_stock, supplier_url FROM v_product_overview;"
```

- `v_product_overview` — список для просмотра: итоговое название (ваше → ИИ → оригинал), статус ИИ, число вариантов, остаток, `min_retail_price_cents`/`max_retail_price_cents` (розничная цена в копейках; `0` — ещё не рассчитана: расчёт цен появится вместе с мониторингом).
- `price_history` — каждое реальное изменение цены/остатка варианта с датой.
- `audit_log` — кто и что поменял в карточке.
- Ваши правки: `UPDATE products SET title_override = 'Новое название' WHERE id = 1;` — оригинал поставщика и текст ИИ остаются, правка попадает в `audit_log`.

`ai_status`: `PENDING` — в очереди, `PROCESSING` — генерируется, `READY` — готово, `ERROR` — не удалось (причина в `task_queue.error_log`).

## 7. Обновление в один клик

1. Запускайте ядро через `scripts/run.sh` (Windows — `scripts\run.cmd`).
2. Нажмите значок Dropship. Если вышла новая версия, появится жёлтый блок «Доступна версия …» → **«Обновить в один клик»**.
3. Ядро завершится, скрипт сам скачает изменения (`git pull`), пересоберёт ядро и расширение и запустит ядро заново. Расширение перезагрузится само примерно через минуту. База и настройки не затрагиваются.

Новая версия «выходит» тогда, когда в репозитории публикуется релиз с тегом `vX.Y.Z` (для владельца репозитория: `gh release create v0.2.0 --generate-notes`, версия в `core-cpp/CMakeLists.txt` должна совпадать). Обновиться вручную можно всегда: `scripts/update.sh`.

Если обновление не удалось, скрипт запускает прежнюю версию — потери данных нет. Обновление рассчитано на установку из `git clone`.

## 8. Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Нет связи с ядром» | Запущено ли `scripts/run.sh`? Не занят ли порт 8765 (`--port`)? |
| «unauthorized» / не пускает | Токен в настройках расширения должен совпадать с `bridge.token`. Удалите файл и перезапустите ядро — создастся новый, вставьте его заново |
| «Не удалось найти цену» | Откройте страницу конкретного товара, а не список/поиск |
| `ai_status = ERROR` | `sqlite3 ~/.dropship/dropship.db "SELECT error_log FROM task_queue WHERE status='FAILED'"` — частые причины: Ollama не запущена, нет ключа API, неверное имя модели |
| ИИ «отключён» в логе ядра | Ошибка в `settings.json` — строка лога скажет, в каком поле |
| Кнопки «Обновить» нет | Ядро запущено не через `run.sh`, или новых релизов нет |
