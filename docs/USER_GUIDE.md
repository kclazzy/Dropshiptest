# Dropship — инструкция пользователя

Dropship работает на вашем компьютере: собирает товары поставщиков, считает цену, следит за ценами и остатками и помогает с заказами.
Все данные (база, ключи) хранятся только у вас. Окно можно закрывать — программа продолжит работать в **трее**
(значок рядом с часами). Полностью выйти: правый клик по значку → «Выход».

## 1. Первый запуск (мастер, 3–5 минут)
1. **Каталог и цены** — нажмите «Создать каталог». Появится локальный каталог и стандартное правило цены
   (наценка 50%, комиссия площадки 15%, налог и эквайринг 6%, минимальная прибыль 300 ₽). Менять можно позже.
2. **ИИ для карточек** — выберите, кто пишет заголовки и описания:
   - *Ollama* — бесплатно, на вашем компьютере (скачайте с https://ollama.com/download и модель — см. `docs/AI_PROVIDERS.md`);
   - *облако* (OpenAI, Claude, Gemini, OpenRouter, Groq, Mistral, DeepSeek и др.) — вставьте ключ API. Ссылки на создание ключей — в `docs/AI_PROVIDERS.md`.
   Шаг можно пропустить: тексты останутся исходными.
3. **Расширение браузера** — см. раздел 2 (можно сделать позже).

## 2. Установка и привязка расширения (Chrome / Edge / Brave)
1. Соберите расширение: `cd extension-mv3 && npm ci && npm run build` (нужен Node 20+). Появится папка `extension-mv3/dist`.
2. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите `extension-mv3/dist`.
3. В программе: **Настройки → Расширение → Показать код** (8 символов, действует 2 минуты).
4. В окне расширения: «Настройки» → «Код привязки» → «Привязать». Готово — это нужно один раз.

## 3. Добавление товара
Откройте страницу товара у поставщика → значок расширения → **«Добавить товар с этой страницы»**.
Товар появится во вкладке **📦 Импорт и Черновики**; ИИ напишет карточку (статус «текст готов»).
Тот же товар повторно не дублируется — обновляются цены и остатки.

## 4. Подготовка и публикация
В черновике откройте товар: проверьте/поправьте название и описание, посмотрите цены по вариантам.
Чтобы цены и остатки уходили на витрину, **укажите ID товара на площадке** (offer_id Ozon или номер объявления Avito) рядом с вариантом и нажмите OK.
Товар переедет во вкладку **🟢 Мои товары**.

> Приложение **не создаёт карточки** на Ozon/Avito: создайте товар в кабинете площадки, затем привяжите. Обновление цен и остатков — автоматическое.

## 5. Магазины и цены (⚙️ Настройки)
- **Магазины** → «Подключить»: Ozon — Client ID, API-ключ, ID склада; Avito — Client ID и Client secret. Ключи шифруются и больше не показываются.
  Если обмен не удался, под магазином появится понятная причина (например, «ключи не приняты»).
- **Правила цен** (кнопка у магазина): диапазоны закупочной цены, наценка, комиссия, налог, округление, минимальный остаток и прибыль.
  После сохранения цены каталога пересчитываются. Калькулятор во вкладке «Импорт» показывает раскладку наглядно.
- **Прокси** (необязательно) — если сайт поставщика блокирует частые проверки.

## 6. Мониторинг
Каждые ~30 минут программа открывает страницы привязанных товаров и обновляет закупочные цены и остатки (читает разметку schema.org).
- Блокировка сайта или сбой сети **не обнуляют остаток** — проверка повторится позже.
- Если страницу сняли (404/410) — остаток на витрине становится 0, мониторинг останавливается.
- Если на странице нет читаемой цены — обновляйте товар повторным импортом через расширение.
- Если поставщику нужен вход в аккаунт, нажмите в расширении «Передать сессию сайта».
История цен — в карточке товара (график и таблица).

## 7. Заказы (🛍️)
Режим **ассистированный**: программа проверяет наличие и прибыль, а выкуп у поставщика вы подтверждаете и оплачиваете сами.
1. Заказы пока **вносятся вручную** (форма внизу вкладки) — автоматическая загрузка с площадок не реализована.
2. Выгодный заказ получает статус «Нужно выкупить у поставщика»; расширение откроет страницу поставщика и покажет значок «!».
3. Оформите заказ у поставщика, затем нажмите «Я выкупил» (укажите номер заказа). Невыгодные или проблемные заказы ждут вашего решения.
4. Когда придёт трек-номер — впишите его. Передача трека в кабинет площадки пока вручную (программа подскажет).
**Защита от двойной покупки:** если результат выкупа неизвестен, программа ничего не повторяет сама — только по вашей кнопке «Повторить». Сначала проверьте заказ у поставщика.

## 8. Обновление
**Настройки → Обновление → Проверить обновления**. Если вышла новая версия, кнопка откроет страницу загрузки на GitHub.
Тихой автоматической замены нет намеренно: так надёжнее и безопаснее. Данные при обновлении сохраняются (папка данных приложения).

## 9. Резервная копия
Скопируйте папку данных приложения (в ней `dropship.db` и `secret.key`). Файл `secret.key` нужен для расшифровки ключей магазинов и ИИ — **без него сохранённые ключи придётся вводить заново**. Не храните копию в открытом доступе.

## 10. Если что-то не работает
| Симптом | Что делать |
|---|---|
| Расширение пишет «Нет связи с ядром» | Запустите приложение (оно может быть в трее). Порт 8765 должен быть свободен. |
| «Код неверный или устарел» | Получите новый код в Настройках → Расширение (живёт 2 минуты, 5 попыток). |
| Текст товара «ошибка ИИ» | Проверьте ключ/адрес в Настройки → ИИ; для Ollama — запущена ли она. Нажмите «Сгенерировать заново». |
| Магазин: «ключи не приняты» | Проверьте Client ID / ключ / склад в кабинете площадки и подключите магазин заново. |
| Цена «не рассчитана» | Для этого диапазона закупочной цены нет правила — добавьте диапазон в правилах магазина. |
| Товар «площадка отклонила» | Проверьте ID товара на площадке и допустимые цены; после исправления привяжите заново. |
