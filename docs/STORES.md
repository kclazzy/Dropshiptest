# Подключение магазинов

Магазин добавляется в **Настройки → Магазины** (шаг 5 — окно; ядро уже умеет принимать ключи и хранить их зашифрованными, AES-256-GCM).

> ⚠ Обмен с Ozon и Avito написан по памяти и вторичным источникам, **не проверен на живых аккаунтах**. Первый запуск делайте на одном тестовом товаре и смотрите ошибку магазина в списке товаров.

## Ozon
1. Личный кабинет Ozon Seller → **Настройки → API-ключи** → создайте ключ с ролью, разрешающей работу с товарами (цены/остатки).
2. Запишите **Client-Id** и **Api-Key** (ключ показывается один раз).
3. Номер **склада** (FBS/rFBS): в кабинете «Настройки → Склады» — числовой идентификатор.
4. В приложении: платформа Ozon → Client-Id, Api-Key, склад.
5. Привяжите товар: впишите `offer_id` (артикул продавца из кабинета) в вариант товара.

Что делает приложение: отправляет **остаток** (`/v2/products/stocks`, пачками по 100) и **цену** (`/v1/product/import/prices`: цена в целых рублях с округлением вверх, минимальная цена для акций, зачёркнутая цена, только если она больше цены).

## Avito
1. Личный кабинет → **Интеграции → API** (раздел для разработчиков): получите **client_id** и **client_secret**.
2. В приложении: платформа Avito → client_id, client_secret.
3. Привяжите товар: в вариант впишите числовой `item_id` объявления.

Что делает приложение: получает токен (client_credentials) и обновляет его сам, отправляет остаток (`/stock-management/1/stocks`) и цену (`/core/v1/items/{id}/update_price`).

## Что пока не умеет
- Публикация новых карточек и получение заказов/трек-номеров по API (возвращают «не поддерживается»): заказы вносятся вручную или через расширение, трек вписывается в кабинете.
- Shopify, WooCommerce, eBay: адаптеров нет.
