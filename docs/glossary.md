# Глоссарий

| Термин | Значение |
|---|---|
| **Cents** | Минимальная неделимая единица валюты (центы, копейки), `int64_t`. Деньги никогда не хранятся во float/double. |
| **bp (basis point)** | 1/100 процента. 30 % = 3000 bp. Проценты из БД переводятся в bp один раз, на границе. |
| **Закупка (C)** | Цена поставщика за единицу. По ней выбирается диапазон правила. |
| **Доставка (S)** | Стоимость доставки поставщика, входит в базу расчёта. |
| **Фикс. наценка (F)** | Фиксированная добавка к базе до применения маржи. |
| **Правило цены (PricingRule)** | Диапазон закупочной цены `[от, до)` + маржа, комиссия площадки, округление, порог остатка, мин. прибыль. |
| **Чистая прибыль** | `розница − комиссия (округл. вверх) − закупка − доставка`. |
| **Психологическое округление** | Наименьшая цена не ниже расчётной, оканчивающаяся на заданные копейки (`.99`). |
| **Платформа (Platform)** | Витрина: shopify, woocommerce, ebay, ozon, avito, wildberries, yandex_market. |
| **Вариант (variant)** | Конкретный SKU товара (цвет, размер) со своей ценой и остатком. |
| **Переопределение (override)** | Правка названия/описания пользователем; приоритет: правка > ИИ > оригинал. |
| **История цен (price_history)** | Снимок цен и остатка варианта при каждом реальном изменении. |
| **Аудит (audit_log)** | Журнал правок карточек и смены статусов заказов. |
| **Задача (Task)** | Строка `task_queue`; воркер захватывает её атомарно и обязан завершить или провалить. |
| **Брошенная задача** | `IN_PROGRESS` с истёкшей блокировкой: возвращается в работу или помечается `FAILED`. |
| **Мост (bridge)** | Локальный WebSocket `ws://127.0.0.1:8765/ws`, по которому расширение и ядро обмениваются JSON-RPC 2.0. Первый пакет — AUTH с токеном. |
| **Токен моста** | 64 hex-символа в `bridge.token`; без него ядро не принимает команды расширения. |
| **Провайдер ИИ** | Источник текстов карточки: локальная Ollama или облачный сервис; выбирается в `settings.json`. |
| **Локальный каталог** | Магазин `platform_type = local`, создаётся при первом запуске; товары лежат в нём, пока не привязаны к реальной площадке. |
| **Скрипт запуска** | `scripts/run.sh` / `run.cmd`: запускает ядро и при коде выхода 75 обновляет программу и запускает её заново. |
